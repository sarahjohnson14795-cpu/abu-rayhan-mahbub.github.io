## Run locally

## Publish free with GitHub Pages
1. Create a GitHub repository named `abu-rayhan-mahbub.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/ (root)` → Save.
5. Your website will be available at `https://abu-rayhan-mahbub.github.io/`.
